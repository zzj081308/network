### 划分vlan

### 配置vlan及接口

创建vlan，分配access和trunk接口

access分配于和主机相连的接口，不携带vlan tag转发

trunk分配于交换机之间的接口，携带vlan tag转发

![](pic/Snipaste_2026-08-01_19-22-57.png)

```
SW1
<Huawei>system-view
[Huawei]sysname SW1
[SW1]undo info-center enable
[SW1]vlan 10
[SW1-vlan10]quit
[SW1]interface Ethernet0/0/1
[SW1-Ethernet0/0/1]port link-type access
[SW1-Ethernet0/0/1]port default vlan 10
[SW1-Ethernet0/0/1]interface Ethernet0/0/2
[SW1-Ethernet0/0/2]port link-type access
[SW1-Ethernet0/0/2]port default vlan 10
[SW1-Ethernet0/0/2]interface Ethernet0/0/3
[SW1-Ethernet0/0/3]port link-type trunk
[SW1-Ethernet0/0/3]port trunk allow-pass vlan 10
```

```

### 配置vlanif

现在在SW3配置vlanif

再在各个主机指定所在网络网关

PC1，PC2网关: 192.168.1.254

PC3，PC4网关: 192.168.2.254

这些vlanif接口上配置的就是网关地址

```
SW3
[SW3]interface Vlanif 10
[SW3-Vlanif10]ip address 192.168.1.254 24
[SW3-Vlanif10]interface Vlanif 20
[SW3-Vlanif20]ip address 192.168.2.254 24
```

#### 防火墙配置

给接口配ip后还需要给接口加入区域

g1/0/0加入trust区域，85优先级

g1/0/1加入untrust区域，优先级5

设置区域访问规则

local和trust互通

trust可以进untrust

untrust不准进trust

```
FW1
<USG6000V1>system-view
[USG6000V1]undo info-center enable
[USG6000V1]sysname FW1
[FW1]interface GigabitEthernet1/0/0
[FW1-GigabitEthernet1/0/0]ip address 192.168.30.2 24
[FW1-GigabitEthernet1/0/0]interface GigabitEthernet1/0/1
[FW1-GigabitEthernet1/0/1]ip address 192.168.40.1 24
[FW1]firewall zone trust
[FW1-zone-trust]add interface GigabitEthernet1/0/0
[FW1-zone-trust]firewall zone untrust
[FW1-zone-untrust]add interface GigabitEthernet1/0/1

[FW1]security-policy
[FW1-policy-security]rule name permit_local_to_trust
[FW1-policy-security-rule-permit_local_to_trust]source-zone local
[FW1-policy-security-rule-permit_local_to_trust]destination-zone trust
[FW1-policy-security-rule-permit_local_to_trust]action permit

[FW1-policy-security]rule name permit_trust_to_local
[FW1-policy-security-rule-permit_trust_to_local]source-zone trust
[FW1-policy-security-rule-permit_trust_to_local]destination-zone local
[FW1-policy-security-rule-permit_trust_to_local]action permit

[FW1-policy-security]rule name permit_trust_to_untrust
[FW1-policy-security-rule-permit_trust_to_untrust]source-zone trust
[FW1-policy-security-rule-permit_trust_to_untrust]destination-zone untrust
[FW1-policy-security-rule-permit_trust_to_untrust]action permit
```

USG 防火墙默认不允许其他设备 ping 防火墙本身的接口

所以SW5ping防火墙需要在服务管理允许接口1/0/0的ping命令

```
[FW1]interface GigabitEthernet1/0/0
[FW1-GigabitEthernet1/0/0]service-manage ping permit
```

### NAT配置

通常公网地址不会有这么多，运营商只会给一个公网地址，内网设备的地址是无法进入公网10.0.0.0网段的

在出口路由器上配置NAT，使得内网地址出去后可以转换为公网地址

配置easy-ip，使得内网设备出去时可以使用出口端口的ip，既可以保证内部信息不被发现，还节省ip

```
R1
[R1]acl 2000
[R1-acl-basic-2000]rule 5 permit source 192.168.1.0 0.0.0.255
[R1-acl-basic-2000]rule 10 permit source 192.168.2.0 0.0.0.255
[R1-acl-basic-2000]quit
[R1]interface Serial1/0/0
[R1-Serial1/0/0]nat outbound 2000
```

抓包PC5可见，ICMP包源地址是10.0.0.1

![](pic/Snipaste_2026-08-12_12-04-42.png)

[R2-Serial1/0/0]quit

[R2-ospf-1]area 0
[R2-ospf-1-area-0.0.0.0]network 10.0.0.0 0.0.0.3
```

#### 配置ppp点对点链路

##### 两边端口配置ppp协议

```
R1
[R1]interface Serial1/0/0
[R1-Serial1/0/0]link-protocol ppp
```

```
R2
[R2]interface Serial1/0/0
[R2-Serial1/0/0]link-protocol ppp
```

##### 进行双向认证

R1 身份：r1/r1pass123，R2 身份：r2/r2pass123

两边存对方的密码，同时各自提供自己用户名密码

```
[R1]aaa
[R1-aaa]local-user r2 password cipher r2pass123
[R1-aaa]local-user r2 service-type ppp
[R1-aaa]quit
[R1]interface Serial1/0/0
[R1-Serial1/0/0]ppp authentication-mode chap
[R1-Serial1/0/0]ppp chap user r1
[R1-Serial1/0/0]ppp chap password cipher r1pass123
```

```
[R2]aaa
[R2-aaa]local-user r1 password cipher r1pass123
[R2-aaa]local-user r1 service-type ppp
[R2-aaa]quit
[R2]interface Serial1/0/0
[R2-Serial1/0/0]ppp authentication-mode chap
[R2-Serial1/0/0]ppp chap user r2
[R2-Serial1/0/0]ppp chap password cipher r2pass123
```

对应关系：

- R1 验证 R2 时，用本地用户 `r2` 核对 R2 发来的 `chap user r2`；
- R2 验证 R1 时，用本地用户 `r1` 核对 R1 发来的 `chap user r1`。

## DHCP配置

如果部门内有新用户接入，又得配ip地址，太麻烦，这时候可以用dhcp自动分配ip地址给主机

ip地址池规划

部门1：192.168.1.100 ~ 192.168.1.250

部门2：192.168.2.100 ~ 192.168.2.250

分别在SW3和SW4上配置dhcp

使能dhcp，设置地址池名称，指定网段网关，排除池外地址

到vlanif接口选择dhcp

```
SW3
[SW3]dhcp enable
[SW3]ip pool vlan10_dhcp
[SW3-ip-pool-vlan10_dhcp]network 192.168.1.0 mask 255.255.255.0
[SW3-ip-pool-vlan10_dhcp]gateway-list 192.168.1.254
[SW3-ip-pool-vlan10_dhcp]excluded-ip-address 192.168.1.1 192.168.1.99
[SW3-ip-pool-vlan10_dhcp]excluded-ip-address 192.168.1.251 192.168.1.253
[SW3-ip-pool-vlan10_dhcp]quit
[SW3]interface Vlanif 10
[SW3-Vlanif10]dhcp select global
```

```
SW4
[SW4]dhcp enable
[SW4]ip pool vlan20_dhcp
[SW4-ip-pool-vlan20_dhcp]network 192.168.2.0 mask 255.255.255.0
[SW4-ip-pool-vlan20_dhcp]gateway-list 192.168.2.254
[SW4-ip-pool-vlan20_dhcp]excluded-ip-address 192.168.2.1 192.168.2.99
[SW4-ip-pool-vlan20_dhcp]excluded-ip-address 192.168.2.251 192.168.2.253
[SW4-ip-pool-vlan20_dhcp]quit
[SW4]interface Vlanif 20
[SW4-Vlanif20]dhcp select global
```
